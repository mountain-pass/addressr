# Decisions Compendium

How `docs/decisions/README.md` is generated, what it truncates, and why the generator must not be run by hand. Split from `external-comms-and-compendium.md` 2026-08-02 (Tier-3 budget rotation).

- **The decisions compendium (`docs/decisions/README.md`) renders only about the first five Confirmation bullets per ADR, so criteria appended at the end of a long `## Confirmation` list never reach the routine architect load surface.** Not a per-bullet character truncation — whole trailing bullets are dropped. Hit 2026-07-26 amending ADR-001: two new criteria added as bullets 6 and 7 (the ones recording that the deploy-only path IS risk-gated) vanished from the compendium entirely, which is precisely the reviewer-invisibility the compendium-refresh discipline exists to prevent. Fix is to COMPRESS rather than append — merge related criteria so the whole set fits, then regenerate and actually read back the rendered `**Confirmation:**` line to confirm each one survived. Reassessment Criteria are excluded from the compendium by design, so body placement there is correct and complete.
- **Never run `wr-architect-generate-decisions-compendium` after editing an ADR — the PostToolUse hook has already rewritten AND `git add`-ed `docs/decisions/README.md` for you, and the shim then destroys that work.** `architect-compendium-update-entry.sh` fires on every ADR edit, so by the time you think to "regenerate", the compendium is already correct and staged (`git status` shows `M ` in the staged column, which is why a bare `git diff docs/decisions/README.md` comes back EMPTY and looks like nothing happened — check `git diff --cached`). The deprecated shim (ADR-078 Option 9, removal pending) then strips `**Decides:**` and `**Related:**` from hook-authored entries, re-prefixes titles into `### ADR-037 — ADR 037: ...`, drops the Oversight field off superseded entries, and mangles `__tests__` into `**tests**` — while still printing a reassuring `wrote docs/decisions/README.md (40 ADRs total — 36 in-force, 4 historical)` and exiting 0. The totals line survives intact, so a count-based check passes and the damage is invisible. Hit 2026-07-27 on the ADR-037/038/039/040 ratification drain; recovered only because the file had been snapshotted to `/tmp` first. If you must run it, `cp docs/decisions/README.md /tmp/before` and diff after — but the right move is not to run it at all.
